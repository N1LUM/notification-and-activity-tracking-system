# Notification & Activity Tracking System

**Описание:**  
Набор Go-сервисов для обработки событий и отправки уведомлений.  
Включает:

- **API Gateway** — точка входа и авторизации
- **Event Worker** — обработка событий из очередей (Kafka/RabbitMQ)
- **Notify Worker** — отправка уведомлений (email, push, SMS)

**Технологии:**
- Go (Golang)
- Kafka и RabbitMQ
- ClickHouse
- Redis
- mTLS для безопасного взаимодействия сервисов

**Структура проекта:**
- Каждый сервис в отдельной директории с кодом и зависимостями
- Общие библиотеки в `internal/`
- Локальные сертификаты для разработки в `certs/` (игнорируются в Git)
